# CAD

| File | What it is |
| --- | --- |
| [`Juno-2-Wide.step`](Juno-2-Wide.step) | **Current frame (Juno-2, 129 mm wheelbase).** Neutral STEP for any CAD package, both frame parts. |
| [`Juno-2-Wide.f3d`](Juno-2-Wide.f3d) | Current frame as a Fusion archive, with the editable timeline. |

The printable parts are in [`../stl`](../stl): part 1 is the main frame and part 2 is the second, smaller piece.

Units are millimetres. The frame's origin is the centre of the stack, with +X towards the camera (front) and +Z up.

Earlier Juno-1 CAD (v1 and Juno-1 Wide) is no longer published here; it remains in the git history.

See the [design notes](../docs/design-notes.md) for how the frame evolved.
